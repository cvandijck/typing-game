# Key Game (simple)

A tiny kid-friendly webpage that shows a character to type. When the user types the correct character the page celebrates; otherwise it displays "Wrong, try again!".

Files:
- `index.html` — main page
- `styles.css` — styling
- `script.js` — game logic (listens for keys; no input field)

How to run:
- Open `c:\Projects\key-game\index.html` in your web browser (double-click or drag to browser).
- Press the shown key on your keyboard. There is no text input box — just press the key.

Visuals
- The page now shows a big, colorful character and a full-screen celebration (confetti, mascot, bright background) when the correct key is pressed. Wrong answers keep the same target so kids can try again.

Notes:
- The game chooses letters (A-Z) and digits (0-9).
- Sound may be blocked by browser until interaction; press a key to enable audio.
